现场照片挂接说明（WindLens 第 17 晚框架）

把现场照片放进本目录（jpg/png），然后在 manifest.json 里登记点位：

[
  {
    "name": "东侧开洞",
    "file": "east_hole.jpg",
    "x": 55.0, "y": 20.0, "z": 30.0,
    "caption": "东侧 2 号开洞局部（2023-05 现场）"
  }
]

- x/y/z 为模型显示系坐标（X 跨向 ±57.3 / Y 高度 0~41.7 / Z 长向 0~316.6），
  3D 视图里会出现对应照片标记（紫色菱形），点击弹出照片与说明。
- manifest.json 为空数组 [] 时框架完全隐藏。
- 双击模型任意部位可局部聚焦（再双击空白处复位）。
